# $ASTROID — Grok Imagine Trailer Script

Built for **Grok Imagine** (text-to-video). Each shot is a self-contained ~6s
clip prompt; generate them individually, then cut together in order. A shared
**style prefix** keeps every clip on-model — paste it in front of each shot
prompt.

> **Compliance (locked):** no yield / profit / "earn" / price / ROI language,
> no financial promises. It's a **game**: mine, shield, stake, raid, vault,
> holders, beta. Keep it cinematic, not a pitch.

**Format:** vertical `9:16` for TikTok/Reels/Shorts; render a `16:9` pass for
X/YouTube. Target ~45–55s. A 15s cutdown is at the bottom.

## Generation tips for Grok Imagine
- Generate **3–4 variations per shot**, pick the best, regenerate the weak ones.
- If a shot drifts off-palette, re-paste the **style prefix** and add
  `consistent cyan-and-ember color grade`.
- Avoid asking Grok to render the on-screen text — it garbles type. Add
  `MINE`, `RAID`, `$ASTROID`, `astroid.club` etc. in your editor (CapCut /
  Premiere / Resolve) for crisp typography.
- For continuity, reuse the **same seed** within a sequence where Grok exposes
  it, and keep camera language consistent (slow push, whip-pan, majestic orbit).
